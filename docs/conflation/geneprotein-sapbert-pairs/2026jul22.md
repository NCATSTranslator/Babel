## Conflation groups

## What the protein side's names are

A UniProtKB record's label is an entry label that Babel builds from the FASTA header: the entry
name, the protein name and `(sprot)` or `(trembl)`. Protein synonyms come only from PR and UMLS
(`config.yaml: protein_synonyms`), so a TrEMBL protein's entry label is its only name. Counts are of
(group, name) rows the gene does not already have.

|---|---:|---:|---:|---:|
| human | 14,650 | 18,988 | 149,200 | 18,978 |
| model organism | 279,694 | 42,500 | 173,699 | 41,315 |
| other | 18,636,612 | 201,286 | 142,092 | 30,764 |
| all | 18,930,956 | 262,774 | 464,991 | 91,057 |

"Groups with one" counts the groups with at least one protein name that is neither an entry label
nor already a name of the gene. Only in those groups does a gene-protein pair tie a gene name to a
protein name that could appear in text.

Is the protein name inside an entry label already one of the gene's names? Where it is, the label
adds only its entry-name prefix.

## Names a gene shares with its own proteins

One string has one embedding, whichever record it was trained under. So a name that a gene and its
protein share already ties the gene's other names and the protein's other names together when
Gene.txt and Protein.txt are trained separately. A gene-protein pair adds a tie of its own only in a
group with a protein-only name and no shared name. "Other" protein names are those that are not
entry labels.
