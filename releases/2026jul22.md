## Known issues and caveats

- Continued with the downloads from 2026jul15 under babel-1.18, but redownloaded CHEBI given many
  parsing changes.
- DrugBank downloads are currently disabled
  <https://github.com/cthoyt/drugbank-downloader/issues/23> -- I used the previously downloaded
  5-1-13.
- HMDB is now behind a Cloudflare bot challenge, so the pipeline can't download it (see
  docs/sources/DownloadPatterns.md). Unlike DrugBank, this is not a reused old download -- I
  downloaded it fresh in a browser on my laptop and copied it to the HPC.
- The `biolink:Food` retype in [PR #918](https://github.com/NCATSTranslator/Babel/pull/918) applied
  at the clique level, so seven cliques that reach DrugBank food evidence through RXCUI/UMLS --
  including D-glucose and tocopherol -- shipped as `biolink:Food` in babel-1.18
  (<https://github.com/NCATSTranslator/Babel/issues/935>,
  <https://github.com/NCATSTranslator/Babel/issues/948>). The fix
  ([PR #948](https://github.com/NCATSTranslator/Babel/pull/948), commit `43157fa7`) is in the
  2026jul22 tag, and `Food.txt` is down to 285 cliques. Spot-check `CHEBI:4167` "D-glucose" in the
  built compendia before publishing -- the reports-only snapshot can't confirm it.

## Areas that changed substantially

This is a large release -- 605.9M CURIEs against 689.0M in 2025sep1, a net 12.1% drop -- and
consumers should expect several compendia to look very different. The headline movements, with what
they trace back to:

- [MAJOR] **Protein is down 38.2%** (275.5M -> 170.2M CURIEs), essentially all of it UniProtKB
  (253.7M -> 149.9M identifiers, \-40.9%). **No PR in this release touches the UniProtKB ingest**,
  the protein completeness report shows `Missing identifiers: 0`, and the run logs record no UniProt
  download or parse errors -- so this looks like an upstream UniProtKB/TrEMBL change rather than
  anything Babel did. Worth confirming against the UniProt release notes before this ships, since
  it is the single biggest change in the build.
- [MAJOR] **PhenotypicFeature is down 78.5%** (483,108 -> 103,707) and `umls` is up 41.9%
  (897,846 -> 1,274,014). These are the same movement: UMLS semantic types T033/T034 were excluded
  from disease-phenotype so that leftover-UMLS re-types them
  ([PR #818](https://github.com/NCATSTranslator/Babel/pull/818),
  [PR #569](https://github.com/NCATSTranslator/Babel/pull/569)), and the UMLS identifiers in
  PhenotypicFeature (365,930 -> 28,761) carried their SNOMEDCT (47,823 -> 6,164) and MEDDRA
  (22,809 -> 6,409) clique partners with them. Consumers resolving a phenotype by UMLS CUI will now
  get a `umls`-file clique instead.
- [MAJOR] **ChemicalEntity is down 87.2%** (4,046,131 -> 518,554), which unwinds the 510% jump
  reported in [2025sep1](./2025sep1.md). The identifiers moved to SmallMolecule (+4.5%, +9.9M):
  INCHIKEY in ChemicalEntity went 1,776,876 -> 55,437 and PUBCHEM.COMPOUND 1,647,448 -> 14,116,
  while the corresponding SmallMolecule rows grew by about the same amounts. Chemicals that were
  previously typed only as the generic `biolink:ChemicalEntity` now get a definite type.
- **MacromolecularComplex is up 1,536%** (1,258 -> 20,579) -- all ComplexPortal species are now
  ingested ([PR #831](https://github.com/NCATSTranslator/Babel/pull/831)).
- **A new `Food` compendium** (932 CURIEs) from the DrugBank retype
  ([PR #918](https://github.com/NCATSTranslator/Babel/pull/918)); see the known issue above.
- **MP arrives in PhenotypicFeature** (31 -> 14,750), kept disjoint from HP
  ([PR #886](https://github.com/NCATSTranslator/Babel/pull/886)).
- **Gene is up 11.7%** (+9.3M, mostly NCBIGene +8.2M), **MGI is up 1,352%** (+537,947), and
  **Publication is up 5.3%** (+4.2M).
